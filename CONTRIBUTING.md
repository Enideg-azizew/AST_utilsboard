Workflow

1. Sync your fork: git pull upstream main
2. Create a branch: git checkout -b feat/your-change
3. Make your changes and add tests
4. Push and open a PR against main

Guidelines

· Follow existing code style; run the linter before committing
· Keep PRs focused — one change per PR
· Use Conventional Commits: feat:, fix:, docs:, etc.
· Update docs and tests alongside code

Issues

· Bugs: include steps to reproduce, expected vs. actual behavior, and environment details
· Features: describe the problem and your proposed solution
